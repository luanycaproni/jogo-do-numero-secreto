# 🎲 Jogo do Número Secreto

Jogo em que o jogador tenta adivinhar um número sorteado, recebendo dicas se o chute é maior ou menor que o número secreto.

🔗 **Jogue aqui:** https://jogo-do-numero-secreto-sandy-psi.vercel.app/

## Tecnologias
- HTML
- CSS
- JavaScript

## Como rodar localmente
1. Clone o repositório: `git clone https://github.com/luanycaproni/jogo-do-numero-secreto.git`
2. Abra o arquivo `index.html` no navegador.
